# Уточнение CatBoost и компактной контекстной сети

## Результат

Обновлены две существующие экспериментальные функции ранжирования русских подсказок. CatBoost учитывает 95 признаков написания и контекста; нейросеть использует последние 48 символов и вероятность завершения слова. Обе работают локально, имеют независимые переключатели, по умолчанию выключены и отключаются общей командой дополнительных функций. В диагностике сохраняются отдельные configured/effective-флаги.

Модели меняют порядок готовых ручных вариантов. Исходное слово и правила автоматической замены остаются под контролем существующей политики. Прежняя модель вероятностей букв для касаний сохранена без изменения весов; её готовность теперь отделена от готовности контекстного ранжирования.

## Качество

Новая проверка проведена на заранее отложенных статьях публичной русской Википедии. Обучение: 2 млн символов и 5 000 синтетических опечаток. Подбор: отдельные 250 тыс. символов и 1 000 опечаток. Проверка: ещё 250 тыс. символов и 1 500 опечаток. В APK нет личных диалогов.

Для 1 477 проверочных строк генератор предложил варианты; правильное слово присутствовало в 1 416. Ошибки — удаление, повтор, перестановка соседних букв и замена на горизонтальную соседнюю клавишу.

| Оценщик | Прежняя версия | Новая версия |
| --- | ---: | ---: |
| CatBoost | 81,79% | 93,64% |
| Контекстная сеть отдельно | 40,76% | 57,01% |
| Вместе | 81,86% | 94,11% |

Это доля правильных первых **альтернатив**, а не точность автоматической замены. Генератор без этих оценщиков дал 83,89%. Контекстная сеть отдельно по-прежнему слабее оценки написания.

На прежнем, уже раскрытом наборе из 926 строк обнаружена регрессия: связка дала 73,33% вместо 74,08%; CatBoost отдельно — 71,92% вместо 73,43%. Поэтому новая версия остаётся экспериментальной: улучшение на новых одиночных опечатках не доказывает улучшения для всех ошибок, реальных переписок и персонализированных бонусов. Модели и вес смешивания после новой проверки не подбирались повторно.

## Размер и задержка

- CatBoost: 128 деревьев глубины 5, 22 036 байт.
- Контекстная сеть: 48×48, 320 216 байт.
- Прежняя модель касаний: 81 848 байт, тот же SHA-256.

Android API 37, эмулятор; по 200 измерений после прогрева:

| Расчёт | Медиана | p95 |
| --- | ---: | ---: |
| CatBoost, один вариант | 0,184 мс | 0,579 мс |
| Контекст, слово из 6 букв | 0,279 мс | 0,404 мс |
| Вероятности следующих букв | 0,100 мс | 0,110 мс |
| Обе модели, три слова из 6 букв | 0,432 мс | 1,100 мс |
| Три длинных входа в установленных пределах | 1,246 мс | 1,442 мс |

p95 означает, что 95% измерений были не дольше указанного времени. Это измерения оценщиков, без генерации кандидатов, чтения редактора, отрисовки и холодной загрузки. Прежний отдельный прогон давал p95 0,291/0,287 мс для CatBoost/контекста; новые оценщики выполняют больше работы. Даже неизменённая модель касаний показала разброс между прогонами. Сравнение не заменяет измерения на физическом телефоне.

## Проверки

- 952 JVM-теста: без ошибок и пропусков.
- 31 Android-тест: без ошибок и пропусков. Проверены переключатели, оригинал/кандидаты, инструменты ввода, касания и независимость ресурсов моделей.
- Дополнительный запуск двух тестов моделей на итоговом APK: успешно; из него получены измерения выше.
- 10 Python-тестов моделей и 8 тестов экспортёра: успешно.
- Совпадение Python/Kotlin по 95 признакам, результатам CatBoost, нейросети и прежним вероятностям касаний: успешно.
- Экспорт CatBoost совпадает с эталоном на 2 856 dev-кандидатах, максимальная абсолютная ошибка менее 2,4×10⁻⁸. Повторное обучение после усиления проверки входов воспроизвело тот же бинарный файл.
- `lintDebug`, `imeIntelligenceBoundary`, `forbiddenRuntimeDependencies`, `privacyGateRelease`, сборка debug APK: успешно.

Первые неуспешные проверки сохранены в локальных журналах: устаревший список зависимостей экспортёра и неверная ожидаемая численность в новом host-тесте. Экспортёр исправлен для компиляции только нужных зависимостей генератора; тест исправлен по проверенному входному набору. Они не считаются успешными прогонами.

Точные идентичности данных, моделей и сборки, результаты и журналы хранятся в игнорируемом `build/typing-refinement`. Методика воспроизведения, лицензия и ограничения: [tools/typing_experiments/README.md](../tools/typing_experiments/README.md). APK не установлен на личный телефон.
