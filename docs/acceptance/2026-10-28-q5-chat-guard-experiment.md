# Q5: post-hoc colloquial protection experiment

This local experiment overlays the seven distinct reviewed colloquial forms on
the existing rare-word lookup in an isolated copy of the observer. The layer is
in memory with a synthetic low-priority rank; it is not a packed dictionary,
production change, APK or independent qualification. The words were selected
after observing the eight source-control failures, so this is disclosed data.

The source-bound `current-product` observer processed all 34,330 chat-regression
rows against the original baseline. The temporary overlay preserved all eight
reviewed occurrences, reducing changes on the unproofread source controls from
41 to 33. Fifteen outputs differed: eight controls and seven synthetic typo cases.
For the seven typo cases the baseline produced a different incorrect word and
the overlay left the typed form unchanged; no synthetic expected correction was
gained or lost. There were no observed exact-Undo failures on overlay changes.
The sample cannot establish false-change or natural typing rates, and exact
membership may suppress desirable corrections in other contexts.

The [numeric evidence](2026-10-28-q5-chat-guard-experiment-evidence.json) binds
the baseline and overlay observations, current project sources, compiled harness,
input corpus and reviewed form list. Thirty-one focused tests passed. This is a
candidate direction only: source provenance, a real packed asset, broad replay,
fresh independent evaluation and device checks remain before promotion. The
installed keyboard and the phone were not changed.

A subsequent [extended parity comparison](2026-10-28-q5-chat-guard-extended.md)
covered 4,720 additional disclosed Russian inputs without non-timing observer
differences. It remains separate from independent qualification.
