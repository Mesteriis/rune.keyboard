numerical imports or input reads, including under optimization. Rescue is also
safe to import without arguments. Disclosed results require an explicit option,
use `historical-disclosed-calibration`, and cannot grant independent/production
qualification. Original numerical thresholds, coverage requirements and search
order are preserved; old source bytes remain indexed by digest/original path.

Source/follow-up recompute scores with exact current model/context bytes and
schema-2 native calibration observations. The old cached score file is unused.
Rows/pool identities, typed finite summaries, parent policies, corpus/held-file
hashes, shared replay resource/opaque-ID proof, code and registries are bound.

and optional configuration are serialized and all captured inputs rechecked
before exclusive publication. Held labels are never parsed by these recipes.

Rescue retains its original fixed public pins and binds secondary cache/training
receipt bytes to the published policy. Its numerical recipe is replayed on those
exact caches with bound morphology and hash-only held data. Generator/runtime and
parent training remain explicitly unverified; cache identity is not a renewed
claim of their execution. No independent mode exists for this disclosed recipe.
