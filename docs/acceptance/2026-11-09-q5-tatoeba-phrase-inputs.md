# Q5: registered inputs for broader full-session replay

The disclosed Russian CC0 Tatoeba chat-shaped corpus has 9,543 selected source
control phrases, each already associated with an excluded source article. The
frozen public ID selection and the pinned source generate 42,153 word stages
for a future full-session controller replay. Both persistent registries now
contain the 29,633 distinct original stage contexts, with source, selection,
source lock and generator/helper identities bound. The source contains public
text; the hashes are unsalted and are not anonymization.

Two independent registrations yielded byte-identical registries. All 59 prior
control entries and 211 prior lexical entries, including compact representation,
and the existing incomplete-coverage declarations were preserved. The first
attempt expanded historical compact entries when serializing the validator's
return value; it was rejected before changing either registry. The final
registrar validates an expanded copy but appends to the original representation.
Its check requires both new entries to match source-derived keys and bindings.

The three source/registration tests, 13 holdout-ledger tests, 10 control-ledger
tests and 27 public-preparation tests passed. CI runs the registration check and
its tests. The generated intermediate registries were removed after use.

This is input registration, not a completed phrase replay: corrections can
change later contexts, and those observed contexts must be registered separately
before reuse. Source spelling is unproofread, and these previously disclosed
phrases are not an independent holdout. No false-change rate, model qualification,
Android device result or broader Q5 completion is claimed.

The subsequent [full-session replay and observed-context registration](2026-11-09-q5-tatoeba-full-phrase-replay.md) are recorded separately.
