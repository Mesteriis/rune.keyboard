# Q6 joint editor replay and evaluation binding

Both joint product evaluators now consult permanent Q6 registries before corpus
or optional scientific imports. Disclosed replay requires
`--historical-reproduction`; original numerical predicates remain in
`numericalGatePassed`, actual editor checks additionally constrain
`observedGatePassed`, and disclosed `passed` is always false. The CLI retains a
nonzero qualification exit and a complete negative report. The pure historical
metric functions are preserved; they are not independent admission APIs.

Current replay receipts use schema 2. Before/after bindings cover every asset,
selected Kotlin source, compiler/JAR/SDK executable input, rows, optional config
and referenced model, driver/harness, source manifest and toolchain manifest.
Generated inputs, raw controller output, host identity map, normalized output,
JAR and logs are hash-bound too. Failures after directory creation preserve a
failed receipt. JDK-distribution/independent-release closure remains Q1 work.

Original source IDs can contain cohort labels. Kotlin now receives deterministic
opaque IDs and the five original input fields; source IDs are restored host-side
after index/status/input alignment checks. The evaluator verifies the actual TSV,
identity map and raw/normalized equivalence, required resource/source closure,
runner/JAR identities and both complete receipts. Old receipts without resource
binding are refused; no historical observation is upgraded by invented metadata.
Original replay/evaluator source bytes are retained by SHA-256 and original path.

Supplied policy model/context and thresholds must match the explicit six/eight-
column config or the bound packaged joint provenance. Follow-up inheritance must
bind the short policy; an optional corpus manifest must describe the actual
holdout, not another hash-consistent file. Independent mode additionally needs
the public-data/registry role and corpus manifest. All inputs, evaluator code and
registries are rechecked before an exclusive sealed report write; the checksum
is an integrity check, not a signature or proof of historical execution.

The existing UTF-16 editor validator verifies snapshot ranges, input identity,
correction edit mechanics and factual flag agreement. Text/caret Undo failure,
changed input/prefix, introduced case-only control changes and introduced expected-
case/layout discrepancies block the observed gate. Existing baseline case changes
and composing-range Undo differences are disclosed separately. The Undo admission
here is the original-text contract plus caret; this does not close every composing,
editor/device or visible-Undo review criterion.

Actual checks:

- Thirteen new stdlib tests pass: both default/optimized CLI refusals, complete
  source/resource/input drift, legacy/incomplete replay refusal, opaque envelope
  and raw identity checks, forged Undo versus actual failure, case-only controls,
  UTF-16/caret handling, model/threshold/config/short-chain binding, corpus cross-
  edges, sealed roles and passing disclosed numbers that cannot qualify.
- Full stdlib: 120 modules / 651 tests, zero failures/errors/skips.
- Full scientific: 23 modules / 76 tests, zero failures/errors and one explicit
  MLX environment skip. CI tools: 41 passing tests.
- The versioned native smoke performs two fresh actual controller/model replays
  on four original disclosed joint rows (short/long and typo/control). It binds
  188 distinct files / 363 named inputs and rejects all 18 isolated output/input
  mutations without mutating packaged sources/models. It also rejects drift
  injected during actual metric calculation and a second report write.
- Both final reports retain `passed=False`. A successful native smoke exit proves
  checks/expected refusal, not model acceptance. The policy is explicitly fixture-
  only and copies packaged thresholds; original training/dev selection and the
  complete historical experiment are not reproduced.
- All packaged model/assets, frozen Kotlin identity and parity bytes are unchanged.
  CI wiring uploads real native receipts, raw/normalized output and reports;
  hosted execution remains unverified, with no push or dispatch performed.

The actual four rows expose limitations of the old metrics: baseline already
capitalizes a correct-name control (`риты` to `Риты`), and one typed prefix differs
from its input before word evaluation. Baseline casing is not attributed to the
joint source; introduced case changes are counted separately. The context-deviating
row cannot support independent qualification. No product-policy change is made
from this small synthetic sample, and original failed reports remain retained.

The fixture's exact membership in the original full holdout and manifest/file
hashes was verified locally; CI checks permanent disclosure and article attribution
but does not reconstruct original membership from large shards. It preserves
historical family labels without certifying new canonical families. Global Q6
coverage, calibration/training entry points, historical source/family gaps and
independent natural qualification remain open. No APK/device change is made.
