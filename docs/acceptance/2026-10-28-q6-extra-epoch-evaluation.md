# Q6 additional-epoch evaluation binding

The additional-epoch evaluator previously emitted an acceptance decision without
checking whether its named fresh test was now disclosed. Default evaluation now
requires the permanent registry gate before optional numerical libraries or
experiment inputs are read. Explicit historical replay retains numerical
criteria in `observedGatePassed`, but always records `accepted=False` and
`independentDataEvaluation=False`.

The receipt binds the frozen dev selection and four supporting reports, dev
observations, selected/original/ranker bytes, main and previous corpus/observation/
candidate-export graphs, the legacy snapshot, code and registries. Dev counts
must fit the actual dev-row count; negative/nonfinite losses and boolean counts
are refused. Captured inputs are rechecked before an exclusive JSON write.
Regression row limits are restricted to explicit historical smoke and are bound.
The original complete evaluator remains archived by digest/original path.

The maintained refinement evaluator now shares the same corpus/export capture
implementation, with its existing alignment, identity and drift guards retained.
The numerical acceptance predicate itself is unchanged; data-role admission is
applied separately.

Actual checks:

- Six receipt tests pass on Python 3.12/3.14, including `python -O` default
  refusal, changed dev artifacts, typed selection flags, path escape, invalid
  numeric dev evidence and an observed passing gate that cannot grant disclosed
  acceptance.
- Full stdlib: 117 modules / 623 tests, zero failures/errors/skips.
- Scientific: 21 modules / 74 tests, zero failures/errors and one explicit MLX
  environment skip. CI tools: 41 tests pass.
- The permanent controlled smoke runs real numerical comparison on four main,
  four previous and four legacy disclosed rows with identical published
  before/after weights. It binds 165 input records, rejects dev-input drift and
  preserves packaged files. The full sealed comparison report is retained.
  The final report-retention change is followed by a focused scientific rerun
  and standalone command.

This controlled dataset is copied from the disclosed refinement subset with
rebased metadata and explicitly synthetic dev-selection support records. It is
not original additional-epoch training or historical epoch-test reproduction;
no numerical fixture result is treated as a qualification. See the
[source/evidence receipt](2026-10-28-q6-extra-epoch-evaluation-evidence.json).
Word-ranking and other evaluation/promotion drivers, historical source/family
coverage and fresh Q6 qualification remain open. No APK is changed.
