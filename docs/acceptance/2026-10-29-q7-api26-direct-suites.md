# Q7: API 26 direct-instrumentation suite evidence

On the task-owned API 26 emulator, the seven scopes listed by the CI routing plan were executed separately using explicitly targeted ADB instrumentation. The general suite ran with the plan's `q4-counters` fixture and four excluded classes. AndroidJUnitRunner reported 351 tests: 303 executed, 48 assumption-skipped, and no failed tests. The direct run took 2,783 seconds. An `OK (351 tests)` line includes the 48 skips and must not be read as 351 executed tests.

The six separately routed scopes passed without skips: personal admission 4, export navigation 1, API 26 picker 1, qualification lifecycle 1, qualification package safety 1, and native runtime 6. The runtime invocation applied the same two excluded model/benchmark annotations as the Gradle configuration. Qualification APKs were built with `runeNativeQualification=true`, inspected to confirm their separate application and target package, and installed only on the task-owned emulator. The regular debug build outputs were restored afterwards. The emulator was stopped and its task-created AVD deleted; the physical Fold was not used.

The regular APK and test APK were already built before this slice; their hashes are recorded, and the committed `app/` and `runtime-llama/` trees have not changed since before that build. This is not by itself a reproducible-build attestation. The separately rebuilt qualification APKs and native test APK are also identified in the [numeric receipt](2026-10-29-q7-api26-direct-suites.json). Runner logs and the qualification build log remain under `build/q7-api26-*`. The logcat capture was restarted after a test cleared it and contains a gap, so it cannot establish that no system crash occurred throughout the full run.

The general skips include Fold-only cases, voice-IME cases, model-specific fixtures and isolated lab/setup cases; skipped cases are not passes. This evidence uses direct instrumentation, not the Gradle connected runner or its fresh JUnit XML gate. API 37 and an actual hosted CI rerun remain outstanding; Q7 stays open. No production source, model, or user device was changed.
