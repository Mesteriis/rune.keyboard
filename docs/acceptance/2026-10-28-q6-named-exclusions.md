# Q6 durable named regression exclusions

The 56 already disclosed EN/RU/ES named cases now have three source-bound
regression entries in the permanent control ledger. The original 24 entries
and every other ledger field are preserved. There are now 27 entries; global
coverage remains incomplete. These spelling examples do not establish lexical
families, training eligibility or independent qualification.

Standalone regressions use their actual empty prefix. Only regression keys
accept an empty context; protected and punctuation keys retain their previous
requirements, and existing nonempty identities are unchanged. Exact duplicate
inputs fail the overlap gate; changing the prefix still fails the disclosed
surface gate. An unknown input still fails with incomplete coverage.

The versioned registration helper reproduces the three entries from the named
runner and binds both sources plus the shared control-key implementation. Its
check is exercised by the existing stdlib CI test module. Missing entries,
changed bindings and duplicate registration fail closed. The generator writes
only a fresh proposed ledger, for review before replacing the versioned file.
