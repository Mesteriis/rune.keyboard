# U9 — optional letters-layer emoji key (partial)

Appearance now offers Emoji key, off by default, with EN/RU/ES labels and search
support. SettingsCodec reads only an explicit Boolean; missing/malformed values
stay false. This is an additive presentation key, emoji_key, with no schema bump
from 4. It follows numberRow's persistence policy, including preservation of a
future schema marker on writes. No typing opt-in or model setting is enabled.

The preference participates in affectsKeyboardView and is passed to LayoutOptions
by both the live service and the embedded preview. On letters it adds one
0.9-unit key, taking Space from 5.65 to 4.75 while preserving the ten-unit bottom
row. Other rows and non-letter layouts retain their existing behavior. Symbols
and Symbols Alt keep their allowed entry even when the preference is off.
Sensitive/raw/numeric editor restrictions cannot be overridden by this option.

Like numberRow, this appearance preference is outside AdditionalFeatures' typing
registry. It does not depend on candidate-strip visibility or the enabled
languages, and disableAdditionalTyping preserves it. The existing registry stays
at 18 typing features; no new feature is hidden from that registry.
