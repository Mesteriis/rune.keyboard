# Smart Typing 0.3 — model cancellation warm reuse, 2026-09-02

Integrated after mechanical commit `bc16e9d1dae774bbf378229bcd97d4273e4c5223`. The adapter previously unloaded even after ordinary request cancellation when the loaded model identity was unchanged. It now discards that response while preserving the validated, fully loaded runtime. A following request can reuse the load.

The final identity check still holds the existing operation read lock and requires a non-null loaded identity. Identity loss or revalidation errors retain unload; failed/partial load retains cleanup. Explicit worker invalidation is authoritative even for unchanged metadata and performs serial unload before subsequent work. Close, memory/unbind invalidation, flag-first cancellation and late-reply suppression remain intact.

The old ActiveModelWatch reused one invalidation flag and did not retire stopped observers. A delayed callback could therefore invalidate a new registration. Android8 explicitly permits callbacks after stopWatching ([AOSP FileObserver source](https://android.googlesource.com/platform/frameworks/base/+/android-8.0.0_r1/core/java/android/os/FileObserver.java)); its JNI observer forwards event masks ([AOSP native source](https://android.googlesource.com/platform/frameworks/base/+/android-8.0.0_r1/core/jni/android_util_FileObserver.cpp)). This establishes the lifecycle defect and a plausible explanation of the failures; the original failing event code was not captured. Per-registration retirement and a deterministic late-callback control are the required next correction.

The independently approved watch fix (`8a39b4e82e8440cf324bb560d988c7c7833bb80642f4767487e12849515e610d`, review `a033f68c4151ac1fee64eec5a3ada1aa3dcf06a207934640a3d0faef4cd8402b`) retires each registration before native stop and synchronizes callback eligibility/delivery with retirement. Readiness waits stay outside that lock. Current unknown/relevant events still invalidate; all original 12 assertions remain unchanged. Three deterministic tests capture real FileObserver callbacks through test-only reflection and cover close, restart and failed restart, including positive current-registration controls.
