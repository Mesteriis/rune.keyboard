# Q5: full-session replay of reviewed chat controls

Eleven previously disclosed public Tatoeba controls were regenerated from the retained CC0 source and the versioned post-hoc review, with each source article verified against the lexical exclusions. Their phrases were replayed in full through the current controller and in-memory editor, with one session per phrase and the local correction/revision cascade active at each word. Two independent executions produced identical observations.

The existing baseline still changed all eight manually reviewed colloquial-preservation cases: `пейринг → рейтинг`, `токсиков → трусиков`, `админку → спинку`, `забанили → заманили`, `бадлон → баллон` in two contexts, `могёт → могут`, and `ебобо → бобо`. Three additional source forms previously classified as possible source typos also changed. These are post-hoc editorial regression labels, not proof of author intent or a population false-change rate. No policy or packaged model was altered.

Across the eleven phrases, the replay observed zero modifications of prior text at a boundary, two case-only changes elsewhere in the phrase and eleven final automatic edits; immediate Undo restored the exact pre-boundary text in all eleven. This is a JVM controller/editor simulation; it does not establish real-device timing or behavior. A separate emulator suite ran concurrently, so no timing claim is made.

The 56 distinct typed/baseline/case-variant stage contexts are bound to both permanent registries. The registration explicitly includes the observed `мэри`/`Мэри` paths because control identity preserves case. Before reporting, the screen checks that every observed stage input and output context is already registered; an unexpected alternative fails closed for separate review. The first diagnostic with only lowercase registration correctly rejected the disclosed uppercase path; final runs succeeded after adding that observed variant. The [receipt](2026-10-29-q5-reviewed-phrase-evidence.json) binds actual source, source lock, review, ledgers, code, assets and toolchain hashes. CI runs this regression and preserves its observations, but no hosted run is claimed.

These eleven already-exposed examples do not qualify a model or establish broad natural chat quality. Q5 remains open for independently verified controls, wider coverage and a fully qualified correction policy.
