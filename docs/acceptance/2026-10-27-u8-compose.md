# U8 — independent Compose editor acceptance (partial)

The new standalone project tools/qa/compose-editor supplies an actual state-based
BasicTextField. It is not included in Rune's settings/dependency graph or product
variants. Only its debug variant is enabled. Its catalog/lock files pin AGP 9.2.1,
Kotlin/Compose compiler 2.2.10, Compose Foundation 1.9.3 and Activity 1.10.1.
Rune's observed kotlinCompilerClasspath also uses 2.2.10; this is a fixed
compatibility sample, not a latest-version recommendation.

The fixture uses the documented InterceptPlatformTextInput API and a remembered
stable interceptor. It delegates the original request through wrappers counting
before/after cursor, selected/extracted/surrounding text and snapshot APIs. It
never fakes responses or editor selection. A snapshotFlow observes the actual
TextFieldState's numeric length/selection for a native status view; no editor text
is published there. Test code observes the fixed public field through its actual
editable accessibility node and alone prepares/verifies clipboard sentinels.

Three real Rune-key cases prove Shift selection and native Cut/Paste/Select all/
Copy; vertical movement, Home/End and selection across a newline; and literal
adjacent input after Paste followed by qualified teh → the correction after a
new Rune Space. Six payload counters are zero before and after these cases.
The test requires explicit runeComposeQa=true and disposable-emulator hardware.
Default opt-out is a skip, never an acceptance pass; an opted-in missing fixture
fails. The helper launches only the explicitly installed independent editor.

Validation:

- The standalone debug APK and strict lint pass. An initial lint failure was
  fixed with its own catalog, explicit backup/transfer exclusions and icon;
  only version-update suggestions for intentionally pinned catalog entries
  have a scoped lint exception. Its merged manifest has no network permission;
  AndroidX Core contributes only the app-local signature receiver permission.
- Rune's 1,226 JVM tests, IME/scoring boundary, release privacy, debug lint and
  debug/test builds pass. The four Rune build/catalog/settings files are byte
  identical to 01e3477, and its unminified debug DEX has no AndroidX Compose
  class descriptors. The QA graph is independent.
- All three focused Compose cases pass, then all thirteen integration cases
  pass together: Compose three, WebView three, EditText panel six, preview one.
  A separate no-opt-in control records three skips and zero feature passes; it
  verifies the opt-out guard without treating skipped cases as acceptance.
  These are actual Android 36 arm64 emulator results with the pinned Compose
  version, not physical Samsung or all Compose implementations/versions.
- The first native attempt failed all three initial text assertions: the label
  node was selected instead of its parent editable node. Numeric length/caret
  already matched, but that did not prove exact text. A bounded hierarchy
  observation identified the actual android.widget.EditText node; both focus
  and text assertions now select that node within the fixture package. Failed
  results remain in evidence; they are not counted as passes.
- Compiler discovery first hit task-scope and cross-project resolution errors
  in temporary host-only probes. The ordinary :app:dependencies report then
  established the compiler version without changing Rune configuration.
- The prior 12,000-row ordinary replay is reused by exact current identities of
  its 88 compilation sources, 18 runtime assets and driver, not rerun. These
  test/standalone sources are outside that harness. Existing EN precision/
  volume limitations and ES holdout's one aggregate false change remain.
- The task-owned emulator was stopped/deleted. No Fold actions, installation,
  owner clipboard acquisition, remote pages, downloaded model or latency claim.

U8 remains open for physical Fold, manual TalkBack and broader lifecycle handling.
The existing RAM boundary flag still has no service-recreation handoff; matching
framework metadata is not universal logical editor identity. This receipt proves
only the listed Compose sample cases. Exact source/APK/log/result bindings, graph
isolation, replay reuse and cleanup are in the adjacent JSON.
