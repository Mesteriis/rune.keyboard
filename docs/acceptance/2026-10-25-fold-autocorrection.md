На выбранный Samsung Fold SM-F966B (API 37) установлена debug-сборка Rune 0.4.2 через USB, обновлением `install -r`. Установленный base APK проверен по SHA-256. Удаление приложения, очистка данных и выдача новых разрешений не выполнялись. Android MCP был недоступен; использован штатный development-процесс проекта с ADB и instrumentation.

## Проверка реальным IME

`FoldAutocorrectionInstrumentedTest` нажимает экранные клавиши, использует настоящий worker/словари/ранжировщик и отдельный процесс тестового редактора с Binder InputConnection. Текст не вставляется через буфер, `input text` или замену содержимого поля. Это программно воспроизводимый набор на физическом экране, не запись движений пальцев владельца.

| Проверка | Результат после исправления |
| --- | --- |
| Обычный набор — 8 явных ошибок | 8 исправлены |
| Правильные/неоднозначные слова — 6 контролей | 6 сохранены, ложных замен нет |
| Быстрый набор с паузами 50/100/150 мс | Все 3 фразы исправлены, последующие слова сохранены |
| Предпросмотр и явный Undo после начала следующего слова | PASS |
| Отмена первым Backspace | PASS |
| Чтение окружения редактора со стороны IME | 0 вызовов всех шести проверяемых API |

Всего **19 случаев**, 3 инструментальных теста — PASS. Публичный набор исправлений: `ссын → сын`, `ггня → огня`, `жкчь → жечь`, `внтз → вниз`, `зочу → хочу`, `смотруть → смотреть`, `заберай → забирай`, `расмотри → рассмотри`. Контроли: `надо`, `мама`, `конь`, `нудо`, `хантера`, `ность`.

Быстрая фраза: `ссын идет домой ` → `сын идет домой `. Измеренная длительность всей фразы: 1553 / 2516 / 3327 мс. Заданные паузы не включают накладные расходы инъекции; это не задержка ранжировщика, кадровая статистика или измерение скорости человека.

## Найденный дефект и исправление

Первый прогон: **18/19**, один пропуск — `расмотри` оставалось без исправления. Исходный неуспешный прогон сохранён и не считается PASS. Нужное слово уже находилось в упакованном словаре; статистическая политика воздерживалась.

В существующую конечную таблицу явных исправлений добавлено `расмотри → рассмотри`. Версия таблицы и её независимого допуска повышена до 5. Цель по-прежнему требует точного присутствия в упакованном словаре; оригинал, регистр, ограничения поля, режим подсказок, персональные запреты и Undo сохраняются. Численные пороги моделей не менялись. Это отдельная проверенная словарная пара, не перекалибровка по раскрытой независимой выборке.

Добавлены регрессии проверки настоящего словаря, быстрого Space, регистра и точной отмены. Host product replay подтвердил `расмотри`, `Расмотри` и вариант после `давай`, включая точный Undo. После установки исправленного APK полный физический прогон дал **19/19**.

## Данные и границы проверки

На время теста отключены запись обучающих примеров, персональное обучение и калибровка касаний, сбор качества и фоновые профили. После каждого метода возвращается полный исходный набор настроек. Хэши настроек сравниваются семантически; личный словарь, калибровка касаний, learning-lab и список защищённых слов проверяются побайтовыми SHA-256 без экспорта содержимого.

Физический fixture пропускается без явного `allowPhysicalDevice=true` до любых настроек/IME setup и никогда не снимает скриншоты/деревья на ошибках. Последующее повторное испытание Undo дополнительно проверяет изолированный fixture с восстановлением настроек. Это отдельная проверка, не замена полного физического прогона.

`testDebugUnitTest` (1055 тестов), `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug`, scoring boundary и `git diff --check` — PASS. Прочие накопленные изменения рабочего дерева сохранены.

Артефакты: `build/fold-autocorrection-20261025/`. `instrumentation.log` / `initial-report.json` — первый FAIL; `instrumentation-fixed.log` / `final-report.json` — полный повторный PASS. `install-receipt.json` и `fix-install-receipt.json` подтверждают APK и сохранность личных хранилищ при обновлениях. Содержимое личной переписки не читалось и не использовалось как тестовые данные.

Проверка небольшого набора на Fold дополняет [независимую оценку качества](2026-10-25-joint-short-correction.md), но не означает 100% точности в переписке, одинаковой скорости на всех приложениях или проверку обоих экранов/переходов складывания.

Итоговая проверка устройства: хэш установленного APK совпадает с локальным, исходные настройки семантически восстановлены, все четыре личных хранилища побайтово неизменны. Rune остаётся выбранной клавиатурой; сохранённый режим — `HIGH_CONFIDENCE`. `final-device-verification.json` фиксирует итог, `isolated-harness-undo.log` — PASS отдельного повторного теста безопасного fixture.
