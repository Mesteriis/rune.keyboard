# Экспорт числовой статистики качества

В debug-сборке откройте **Настройки → Качество набора на устройстве → Экспорт
статистики качества**. На отдельном экране можно выбрать файл через системный
диалог. Выгрузка содержит числовые агрегаты и фиксированные названия полей,
без набранных слов и сообщений. Запись диагностического текста для неё не нужна.

Экран управления диагностическими журналами предназначен для журналов; кнопка
статистики находится на экране качества. Такой маршрут сохраняет раздельные
границы доступа диагностического регистратора и хранилища числовых метрик.
Release/profile-провайдеры дополнительных элементов пустые; кнопка и Activity
экспорта доступны только в debug-сборке. Сама выгрузка и её формат не изменены.
