**Live editor** below means the resident Rune IME and actual editor transactions across the `:qa_editor` InputConnection, with actual key/strip interactions where the test performs them. It does not mean arbitrary third-party editors or physical hardware. **Live fake-model Binder** means the live resident controller and production coordinators/client, the real remote service/worker transport, and the actual remote editor. [LiveFakeModelBinderFixture:89](/Users/avm/projects/Personal/rune-keyboard/app/src/androidTest/java/io/github/mesteriis/rune/keyboard/qa/LiveFakeModelBinderFixture.kt:89) substitutes fixed lexical input/readiness and routes binding to the controlled debug numeric engine. It validates exact public request payload/identity. It does not exercise the production disk-readiness factory, packaged lexical quality, JNI, GGUF inference or model accuracy.

**Controller-to-editor Binder** uses an independent production controller and real editor executor/InputConnection. It is a stronger editor transaction test than a successful-write counter, but is not the complete resident coordinator/UI path. **Service Binder/controller-only** uses real model-service transport but an editor-write callback returning success, or tests a client alone. These are distinguished explicitly below.
