# Russian Tatoeba CC0 source snapshot

This is the Russian CC0 export identified by `tatoeba-source-lock.json`,
downloaded from [Tatoeba](https://downloads.tatoeba.org/exports/per_language/rus/rus_sentences_CC0.tsv.bz2).
The export is labelled CC0-1.0; see the [Tatoeba downloads page](https://tatoeba.org/en/downloads).
The pinned snapshot was last modified 2026-10-24. Each record provides a
sentence ID, language, text and last-modified timestamp. The separate detailed
export lists the account that owns a sentence at export time. Prior Rune
experiments used this snapshot. It is retained for reproducible disclosed regression,
not independent evaluation. The generator verifies the exact lock and compressed
source bytes, and filters to source articles already excluded in the ledger.
