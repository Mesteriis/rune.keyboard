# Rune Smart Typing 0.3 packaged lexicons

The application assets under `smarttyping/lexicon/` are the selected, modified RU/EN/ES dictionary
components. They remain separate from application code and from each other's licenses. The exact
paths, SHA256, sizes, word/node counts and notice identities are in `packed-asset-manifest.json`.

* `en.trie` and `en.trie.lengths`: SCOWL, including its contributing WordNet/UKACD material. Preserve
  the complete `notices/SCOWL-Copyright.txt`; a shorthand MIT label is not a replacement.
* `es.trie` and `es.trie.lengths`: the separate LibreOffice Spanish dictionary under the selected
  MPL 1.1 option. Original license and attribution remain in `ES-LICENSE.md`, `ES-MPL-1.1.txt` and
  `ES-README.txt` under `notices/`. Corresponding original dictionary and transformation sources
  remain available through the pinned source links/identities below and the repository tools.
* `ru.trie` and `ru.trie.lengths`: the separate LibreOffice Russian dictionary, Alexander I. Lebedev
  terms and attribution preserved in `notices/RU-Lebedev.txt`.
* `frequency/{en,es,ru}.ranks`: separate modified FrequencyWords content under CC-BY-SA 4.0,
  attributed to Hermit Dave/FrequencyWords and its OpenSubtitles2018 provenance. Preserve
  `notices/FrequencyWords-README.md` and `notices/CC-BY-SA-4.0.txt`. Repository code's MIT license
  does not replace the data license. Source ranks map to canonical terminal ordinals; missing keys
  use a sentinel. Frequency values are not embedded in RTR1/LEN1 orthographic components.
* `case/{en,es,ru}.case`: exact RNC1 lowercase-to-title-case records derived from the corresponding
  frozen original-case surface forms. A record exists only when that lowercase key has one canonical
  title-case source spelling. Its ambiguity bit remains false when the source also contains a lowercase
  surface. These assets provide explicit suggestions for names and geographic names; they do not
  authorize automatic replacement.

All 14 original notice files are copied verbatim, including historical Hunspell host-tool notices.
Hunspell binaries, original source archives, expanded word lists, frequency TSVs and models are not
APK inputs. RTR1 stores the normalized terminal trie; LEN1 stores exact descendant length ranges;
RNK1 stores terminal frequency ranks; RNC1 stores only canonical case and ambiguity metadata. The
normalization and finite transformation scope remain the
reviewed source pipeline's NFC/lowercase/NFC, scalar ordering, maximum 32 codepoints, with accents,
ñ and ё retained. No vocabulary or frequency source is regenerated by packaging.

`source-lock.json` contains immutable upstream commits, URLs and input hashes.
`frozen-output-manifest.json` identifies the reviewed canonical/source outputs.
`packed-source-provenance.json` links the packaged components to these records and the actual
repository transformation source hashes. Sources and change descriptions are in
`tools/lexicon/smart-typing-0.3/`, including `THIRD_PARTY_NOTICES.md`, `provenance/`, `scripts/`,
`benchmark/source/builders/`, and `build_packed_assets.py`. These records preserve source availability
and attribution; they do not relicense third-party data or assert a new cold reproduction run.
`canonical-case-manifest.json` pins the source surface hashes, builder hash, byte lengths, record
counts and final asset hashes.

## Offline staging and normal builds

Use committed reviewed asset bytes in normal Gradle/CI builds. Gradle has no network or generation
dependency for lexicons. To reproduce/stage an explicit offline set after the separately documented
source/index/rank builders have produced their pinned outputs, run from the repository root:

```sh
python3 tools/lexicon/smart-typing-0.3/stage_packed_assets.py \
  --source-package tools/lexicon/smart-typing-0.3 \
  --index-root build/reviewed-index \
  --rank-root build/reviewed-ranks \
  --output build/reviewed-apk-stage
```

Paths are explicit examples, not implicit prototype dependencies. `--rank-root` contains the
direct RNK1 builder's `rank-assets/`; `--index-root` contains `assets/*.trie{,.lengths}`. Staging
checks every declared byte length/hash, refuses drift/unlisted files/symlink output paths, and writes
only the explicit build child. `asset-inventory.json` is the exact copy allowlist for
`app/src/main/assets/`. Review it before copying. Nine binary files must be stored uncompressed in
the APK for `AssetManager.openFd`; AGP `androidResources.noCompress` is limited to their extensions.
All original notices/provenance use normal packaging. Actual APK size and Android load behavior must
be measured on the built APK; raw component bytes and host tests are not those measurements.
