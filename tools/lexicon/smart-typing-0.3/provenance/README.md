# Reviewed source-run provenance

These files are unchanged snapshots from the approved source prototype. They
record archive-member identities, the finite profile counts, two-clean-SCOWL
reproducibility, the reviewed host toolchain, and source-review correction evidence.
`reviewed-source-profile.md` contains historical prototype commands and limitations;
use the parent package README and `pipeline.py` for the promoted workflow.

This directory contains metadata and review evidence, not downloaded dictionaries,
archives, host executables or generated word-form assets. Full word witnesses and
new run manifests are emitted under the caller's explicit ignored build directory.
The snapshots do not claim that the promoted package has had a new cold rebuild.
